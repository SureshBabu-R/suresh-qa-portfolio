# Suresh Babu — QA Automation Portfolio

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace `YOUR_EMAIL@example.com` with your professional email.
- Verify experience duration and previous-company dates.
- Add a GitHub profile link if you want one displayed.
- Review project descriptions for confidentiality.
- Optionally add a downloadable resume PDF.

## Publish free with GitHub Pages
1. Create a public GitHub repository, for example `suresh-qa-portfolio`.
2. Upload `index.html` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will provide your public website URL after deployment.
